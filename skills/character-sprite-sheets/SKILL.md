# 角色多角度转向表与表情反应表

一套交付两张独立正方形图集。使用当前环境实际可用的图片生成工具；本技能提供生成规则，不提供模型额度。工具参数按当前接口定义映射，不假定存在 ask_human、reference_image_urls 或特定模型。用户指定模型时遵从其偏好。

## 身份与画风

用户参考图作为两张图共同的身份锚点。先列出不可变化的脸型、五官比例、肤色或毛色、发型花纹、耳朵与身体结构、配饰及服装颜色。两次生成共享完全相同的身份与画风描述，并实际附带同一参考图。

原创角色无参考时先生成正面锚点供确认；已有明确参考时直接使用。只给知名角色名时核实具体版本，不编造外观。缺失且影响结果的服装、画风、产出数量问题合并询问，已有答案不重复问。

默认沿用参考画风；可选 Q 版贴纸或复古手绘。两张图的描边、配色、光照和胸像尺度一致。

## 方向图：directions-25

5 列 × 5 行，行优先编号 0–24，中间第 12 格为平视正面。左右一律以观看者画面为准。

- 列从左到右：朝画面左侧 90°、左前方 45°、正面 0°、右前方 45°、朝画面右侧 90°。
- 行从上到下：明显抬头、轻微抬头、平视、轻微低头、明显低头。建议俯仰约 +30°、+15°、0°、−15°、−30°，以角色结构自然为准。
- 每一格组合对应行的俯仰与对应列的转向。所有格子保持同一个中性友好表情，不用嘴型变化替代俯仰，不把五行当作随机情绪候选。
- 仅头部、视线及必要的颈部转动；尽量固定躯干、肩膀和服装，不新增道具。

## 反应图：reactions

3 列 × 3 行，全部平视正面，行优先编号 0–8：

| 编号 | 表情与装饰 |
|---|---|
| 0 | 眯眼笑，无额外符号 |
| 1 | 开心，头顶红色爱心 |
| 2 | 兴奋，头顶黄色星星 |
| 3 | 惊讶，大眼、O 型嘴，无额外符号 |
| 4 | 星星眼，瞳孔为黄色四角星 |
| 5 | 害羞，闭眼微笑、粉色腮红线 |
| 6 | 困倦，闭眼张嘴、头顶蓝色 Zzz |
| 7 | 晕眩，螺旋眼、波浪嘴 |
| 8 | 大笑，眯眼张嘴，无额外符号 |

只在指定格子添加符号。用户修改表情清单时同时说明新索引映射需要更新播放器。

## 几何约束（两张图共用）

正方形画布，固定均匀单元格，无可见网格线、文字、编号、场景或其它角色。每格独立完整，不跨格。统一的是身体尺度与身体底部基线，不是含装饰的外接框；爱心、耳朵、嫩芽和星星不能使身体缩小或整体下移。

身体底部建议在单元格高度的 90% 处；所有可见内容距离格边至少 5%，头顶预留装饰空间。横向按身体中心对齐，不按爱心或尾巴的外接框居中。方向和反应图的单元格尺寸不同，身体占单元格的比例保持一致。

优先原生透明背景。若工具透明效果不可靠，生成纯白底原稿后使用前景分割抠图；不得把所有白色像素透明化，以免删除白毛、眼白和服装。没有可靠抠图工具时明确交付白底待处理版本，不声称已透明。

## 提示词组装与生成

两次独立调用分别生成两张图。共同部分依次写入：身份特征、画风、几何约束、一致性锁与无场景约束；仅替换网格和各格变化轴。可附已有图集作为第二张版式参考，身份参考始终优先。明确只有指定角度或表情允许变化。

## 检查与交付

逐格检查身份、角度梯度、表情顺序、装饰完整性、身体尺度、底部位置和邻格串入。提示词不能保证精确网格，必须检查实际结果。单格问题可参考锚点重新生成整张；避免无上限重试，一轮修正后仍不合格应说明剩余问题再决定后续。

交付方向与表情图各一张，保留原稿。网页使用透明静态 WebP 图集，透明通道无损、颜色压缩可用质量 85 起测；压缩后重新检查透明度与切框。缺少转换工具时交付透明 PNG，不仅改扩展名。

本资产由指针/点击选择状态，不按 25 格顺序播放；APNG/GIF 不能直接替代交互图集，也不承诺栅格视频可直接变为矢量 Lottie。
